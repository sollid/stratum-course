# Начало курса

Ниже готовый результат проверки установки. Его подготовила программа, не ты.

!`course-run selfcheck --soft`

## Что сделать тебе

1. Выведи текст выше ученику слово в слово, без пересказа и без своих советов.
2. Если текст выше начинается не со слов «Установка работает.», остановись: ничего больше не запускай.
3. Иначе создай учебную папку одной командой (в Windows через PowerShell, на Mac через Bash). Папка из аргумента команды: `$ARGUMENTS`.
   - Если аргумент пустой, запусти ровно: `course-run folder create --data "${CLAUDE_PLUGIN_DATA}"` (папка `claude-course` в домашней папке).
   - Если аргумент есть, запусти ровно: `course-run folder create "<папка>" --data "${CLAUDE_PLUGIN_DATA}"`, подставив вместо `<папка>` аргумент без изменений. Запускай команду, только если в аргументе есть лишь буквы любого языка, цифры, пробел и знаки `.` `_` `-` `~` `/` `\`, а двоеточие стоит только вторым знаком (`C:`). Иначе не запускай, а скажи ученику: «Назовите папку проще, только буквами, цифрами, пробелами и знаками . _ - и введите /course:start ещё раз».
   - Не добавляй к команде ничего, кроме этого.
4. Выведи текст, который напечатала команда, слово в слово. Папку создаёт программа: сам ничего не создавай и не копируй.
5. Больше ничего не делай и не запускай.
6. Не читай, не открывай и не показывай файлы в папке данных плагина (`${CLAUDE_PLUGIN_DATA}`): там лежит токен устройства.
