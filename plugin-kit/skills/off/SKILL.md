# Выключение пакета

Ниже готовый список пакетов этого компьютера. Его подготовила программа, не ты.

!`kit-run list --data "${CLAUDE_PLUGIN_DATA}" --probe "${user_config.probe_hooks}" --flat "${user_config.flat_names}" --soft`

## Что сделать тебе

1. Имя пакета из аргумента команды: `$ARGUMENTS`.
2. Если аргумент пустой, выведи список выше человеку слово в слово и скажи одной фразой: «Какой пакет выключить? Введите /kit:off и имя пакета». Больше ничего не запускай.
3. Если аргумент есть и состоит только из маленьких латинских букв, цифр и дефисов (от 2 до 30 знаков, первая буква), запусти ровно одну команду через инструмент Bash (на Windows `kit-run` сам запускает PowerShell; через PowerShell и cmd эту команду не запускай): `kit-run off '<имя>' --data "${CLAUDE_PLUGIN_DATA}" --probe "${user_config.probe_hooks}" --flat "${user_config.flat_names}"`, подставив вместо `<имя>` аргумент без изменений и обязательно в одинарных кавычках (в двойных оболочка выполнила бы `$(…)` и обратные кавычки; одинарные кавычки в имени не допускаются, такое имя не запускай). Иначе не запускай, а скажи человеку: «Имя пакета не подходит. Введите /kit:off и имя пакета из списка».
4. Выведи текст, который напечатала команда, слово в слово. Файлы убирает программа: сам ничего не удаляй, не создавай и не правь.
5. Больше ничего не добавляй и ничего не запускай.
6. Не читай, не открывай, не ищи и не показывай файлы в папке данных плагина (`${CLAUDE_PLUGIN_DATA}`) и любые файлы с токеном.
