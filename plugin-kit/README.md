# Плагин kit: общие правила команды

Плагин ставит на компьютер пакеты правил вашей команды. Команды: `/kit:install` (поставить), `/kit:check` (что стоит), `/kit:update` (обновить), `/kit:off <имя>` (выключить пакет), `/kit:on <имя>` (вернуть). Привязка устройства — та же, что у плагина курса: сначала `/course:connect`.

## Что нужно и как поставить

Нужны Claude Code с платной учётной записью Claude, плагин курса `course`, установленный и привязанный к сайту (`/course:connect`; токен устройства kit читает у него и не копирует), и Windows 11 (хватает PowerShell) либо Mac или Linux (`sh`, `curl`, `awk`). Пакеты правил даёт руководитель команды на сайте.

Плагин лежит в том же открытом репозитории и в том же каталоге `stratum-course`, что и курс. Команды вводятся в Claude Code (из терминала то же, с `claude plugin …` вместо `/plugin …`), после установки Claude Code перезапускают.

Каталог ещё не добавлен (плагин курса ставили не из этого каталога или не ставили):

```text
/plugin marketplace add https://raw.githubusercontent.com/sollid/stratum-course/main/.claude-plugin/marketplace.json
/plugin install kit@stratum-course
```

Плагин курса уже стоит (каталог у вас есть, но его копия сделана до выхода набора): вместо первой команды введите `/plugin marketplace update stratum-course`, затем `/plugin install kit@stratum-course`. Так же обновляется и сам набор.

## Что кладёт на машину

- Правила: `~/.claude/rules/stratum/<пакет>/<файл>.md` (на Windows `%USERPROFILE%\.claude\rules\stratum\`). Claude Code читает их в каждом проекте. Если ваша копия Claude Code не грузит подпапки, включите в настройках плагина «Плоские имена правил»: файлы лягут как `rules/stratum-<пакет>-<файл>.md`.
- Данные плагина (`~/.claude/plugins/data/kit-<каталог>/kit/`): `state.txt` (по строке на пакет: имя, версия, статус, хеш, время), `<пакет>/manifest.txt` и `deny.txt`, `backup/` (копия всего, что плагин заменил или убрал), `loaded.log`, `last-bg`, `probe/`.
- Чужие файлы плагин не трогает: если нужное место занято файлом, которого он не создавал, пакет не ставится.

## Как убрать всё руками

1. Удалите папку `~/.claude/rules/stratum/` (при плоских именах — файлы `~/.claude/rules/stratum-*`).
2. Удалите плагин командой `/plugin uninstall kit`; вместе с ним Claude Code убирает папку данных (если оставил, удалите `~/.claude/plugins/data/kit-<каталог>/`).

## Что уходит на сайт

Только имя пакета, версия, статус (`ok`, `files`, `not_loaded`, `absent`, `off`), время, система (windows, mac, linux), версия плагина и уровень движка; токен — только в заголовке на адрес, записанный при привязке. Не уходят: пути, имена и содержимое файлов, имена проектов и папок, имя компьютера и учётной записи, текст разговора, содержимое `loaded.log` и `deny.txt`.
Руководитель команды видит ваше имя и статус пакетов; об этом сказано на странице подключения. Набор — договорённость: `/kit:off` выключает пакет, сайт покажет «не стоит».

## Устройство

Скрипты `scripts/kit.sh` (Mac, Linux) и `scripts/kit.ps1` (Windows, PowerShell 5.1) дают одинаковый вывод. Хуки (`probe/hooks.json`: журнал загрузки правил, запреты, фоновый отчёт раз в сутки) в выпущенную сборку не входят, поэтому настройка «Проверка загрузки правил и запреты» без них ничего не включает.
Хук запретов — страховка, а не граница: при сбое разбора ввода (не JSON, нет нужного поля, путь стоит после очень длинного поля больше 256 КБ) он инструмент не останавливает; Grep, Glob и упоминания `@` он не видит. Фраза отказа хука не подсказывает способа обхода; пакет выключает человек командой `/kit:off`.
`/kit:off` и `/kit:on` запускаются только через инструмент Bash: `bin/kit-run` сам проверяет имя пакета до оболочки. `bin/kit-run.cmd` для них небезопасен (cmd.exe разбирает `&` в имени), навыки им не пользуются.
Навыки запускаются только через инструмент Bash (через PowerShell и `kit-run.cmd` — нет: путь профиля с `&` разорвал бы команду); имя пакета для `off` и `on` передаётся в одинарных кавычках.
Сколько запросов: `/kit:install` — до трёх, а если сайт ответил 422 `split` (положенное больше 200 КБ) и запрос делится пополам, — до пяти (список, полный запрос, две половины, итог).
Известное ограничение: плоские имена `stratum-<пакет>-<имя>.md` неоднозначны (пакет `team` с `x-y.md` и пакет `team-x` с `y.md` дают один путь); разделитель выберем после проверки на живой установке, раскладка по умолчанию выключена.
В строке запрета пакета `?` не допускается (особый знак только `*`): такой пакет не ставится.
